# 文字转语音程序运行说明

本程序提供了两种运行方式，并支持Edge TTS和VRChat OSC功能：

## 1. 使用run_tts.bat（推荐）

双击`run_tts.bat`文件即可启动程序。这种方式使用pythonw.exe运行程序，不会显示控制台窗口，使程序看起来更像一个原生Windows应用程序。

## 2. 使用run_tts_universal.bat（通用版）

如果您在不同的电脑上运行本程序，或者Python安装路径不同，请使用`run_tts_universal.bat`。这个批处理文件会自动查找pythonw.exe的路径，更具有通用性。

## 3. 直接运行（不推荐）

您也可以通过命令行运行以下命令启动程序：
```
python text_to_speech.py
```
但这种方式会显示一个控制台窗口，影响用户体验。

## 程序功能说明

1. Edge TTS功能
   - 提供高质量的语音合成服务
   - 支持多种中文语音选择
   - 语音更自然流畅

2. VRChat OSC功能
   - 自动将输入的文本发送到VRChat聊天框
   - 实现文字与语音的同步显示

3. 界面功能
   - 单行文本输入框，按回车键快速转换
   - 历史记录框显示已转换的文本
   - 可选择不同的音频输出设备

## pythonw与python的区别

- `python.exe`：运行Python脚本时会显示控制台窗口，适合需要命令行交互的程序
- `pythonw.exe`：运行Python脚本时不会显示控制台窗口，适合GUI程序

对于本文字转语音程序这类带有图形界面的应用，使用pythonw.exe运行可以获得更好的用户体验。

## 注意事项

1. 如果程序运行时出现错误，但因为使用pythonw而看不到错误信息，可以尝试使用python.exe运行程序以查看错误信息
2. 确保已安装程序所需的所有依赖包（可通过`pip install -r requirements.txt`安装）
3. 如果批处理文件无法正常运行，请检查您的Python安装路径是否与批处理文件中的路径一致
4. VRChat OSC功能需要VRChat处于运行状态才能正常使用
